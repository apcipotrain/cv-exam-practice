# 路线调试与优化记录

## 1. 黑白图是什么意思

`auto_color_mask_reference.png` 是旧的自动颜色阈值检测图。

白色像素表示：程序根据颜色、亮度、饱和度判断“这里可能是手绘路线”。  
它不是最终路线，也不等价于飞行轨迹。

右下角出现一大片白色，是因为操场、亮色地面、局部高饱和区域被误判为路线。这说明单纯依赖颜色阈值不稳定。

因此当前正式路线没有使用这张黑白图，而是采用：

```text
人工控制点 → 重采样 → 平滑飞行轨迹
```

最终路线应以 `route_overlay.png` 和 `data/annotations/route_points.json` 为准。

## 2. 当前路线文件

- `route_overlay.png`：最终路线叠加在校园俯视图上的检查图。
- `bev_sample.png`：800x800 BEV 面板样例。
- `auto_color_mask_reference.png`：旧自动阈值检测，仅保留作调试反例。
- `route_points.json`：渲染视频实际使用的路线点。

如果目录里还有旧文件 `route_mask.png`，它只是旧命名残留，可以删除；不影响当前程序运行。

## 3. 下一步优化重点

当前路线已经基本正确，后续优化不应该继续纠结颜色阈值，而应集中在视频质量：

1. 继续丰富终点附近场景，减少末段空旷感。
2. 增加更多建筑体块，让 PRIMARY 和 COMPANION 的遮挡、透视更明显。
3. 调整伴飞相机，使主无人机在更多帧中更醒目。
4. 美化 BEV 视图，比如同时绘制主无人机路线和伴飞路线。
5. 最后再做视频格式、自评表、readme 和 tar 结构检查。
