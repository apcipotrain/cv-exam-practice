1. 使用的 AI 系统和工具：
使用了 OpenAI Codex 辅助阅读题目、分析实现思路、编写与调试 Python 代码；使用 Python、OpenCV、NumPy 进行图像处理、路线提取、抽象场景建模、三视图渲染和视频生成；使用 FFmpeg / OpenCV VideoWriter 将逐帧结果编码为 mp4 视频。

2. 使用的外部资产或信息来源：
使用了题目发布包中提供的输入文件，包括 route_ref.png、tju_overview_60k_4x4_preview_3000x2000.png、tju_overview_60000x40000_4x4_q92.jpg，以及题目给出的及格效果示例图。未额外使用互联网地图、第三方校园模型或其他外部素材。

3. 图像米制尺度估计方法：
建模中采用题目提供的校园俯视图作为尺度参考，并在程序中设定 3000×2000 预览图坐标到建模世界坐标的比例为 3 像素 ≈ 1 m，即 PIXELS_PER_METER = 3.0。最终路线来自 refined_route_points.json。按照题目要求，在建模世界坐标中以约 1 m 间隔对主无人机地面投影轨迹采样为折线，并累加相邻采样点距离，得到主无人机地面投影轨迹总长度约为 584.83 m。该长度为路径总长度，不是起点到终点的直线距离。

4. 整体实现流程：
提取并修正路线，在 BEV 中叠加路线和视锥；根据路线抽象生成道路、建筑、水体和树木，设置主无人机与伴随无人机相机，逐帧渲染三视图并合成为 mp4 视频。
