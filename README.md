# 计算机视觉机试练习项目

本仓库整理了一组脱敏后的计算机视觉机试练习代码。公开版本只保留“某校练习任务”的工程实现，不包含原始题面 PDF、课程材料、教师信息或超大原始数据。

仓库重点保留可复用的工程流程：数据结构检查、相机参数转换、背景融合、路线提取、抽象场景建模、三视图渲染和视频生成等。

## 项目目录

- `problem1_gaussian_splatting/`：题目一，围绕逐帧 3D Gaussian 数据、COLMAP 相机、人物 mask、背景融合和视频渲染展开。
- `problem2_open_3d_campus/`：题目二，围绕校园俯视图路线提取、无人机 PRIMARY / COMPANION / BEV 三视图可视化展开。

## 开源说明

本公开版本刻意不包含：

- 原始题目 PDF 或课程资料；
- 超大原始输入图像；
- 中间调试帧、临时视频和缓存文件；
- 可指向具体学校、教师或课程的非必要信息。

题目二的最终交付视频体积较小，因此保留在 `problem2_open_3d_campus/deliverables/video.mp4` 中用于展示结果。

## 环境安装

```bash
pip install -r requirements.txt
```

每个题目的运行方式见对应子目录的 README 或文档。
